## 1. 자산 연수익률 (total_asset)

**시트:** `총자산연수익률` (Google Sheets)

**입력 위치:**

| 탭 | 용도 | 입력 방식 |
|---|---|---|
| 월별입금 | 현금 흐름(입금/적금/연금) 기록 | 매월 새 행 추가 (참고용, 위젯엔 안 씀) |
| 연말평가 | 자산 스냅샷 (날짜 + 계좌별 평가액) | **매월 1행씩 새 행 추가** |
| 설정 | 시스템 설정값 | 거의 안 건드림 |
| 대시보드 | 시트 안 시각화 | 자동 계산 |

**규칙:**

- **연말평가 탭이 home의 "순자산 위젯" 데이터 소스**다.
- 한 달에 **한 번**, 같은 시점에 자산 스냅샷 입력.
  - 예: `2026-05-18` 한 행, `2026-06-18` 한 행, …
- 행을 새로 추가하는 거지 **덮어쓰기는 안 함** — 같은 날 두 번 입력하면 두 행이 됨.
- home 위젯의 "지난달 대비"는 가장 최근 두 행의 평가액 차이로 자동 계산.

**갱신 흐름:**
```
구글 시트 입력 → Apps Script가 doGet으로 JSON 반환 → home 위젯이 fetch
```

## 2. 부부 주식 합산 (family_portfolio)

**입력 위치:** `family_portfolio` 앱 — **시트 직접 수정 X**

시트(`Holdings_W`, `Holdings_H` 탭)에는 초기 데이터만 있고, 이후 모든 입력은 앱에서 진행.

### 종목 추가
1. family_portfolio 앱 열기
2. 우측 상단 **"+" 버튼**
3. ticker / 이름 / 시장 / 계좌 입력
4. 저장 → 시트에 새 행 자동 추가

### 종목 수정
1. 종목 카드 탭
2. 편집 모드 진입
3. 수량 / 평단가 수정
4. 저장

### 종목 삭제
1. 종목 카드 우측 삭제 버튼
2. 확인 → 시트에서 행 제거

**참고:**

- 시세(현재가)는 앱에서 자동 조회 (Naver Finance 등). 시트엔 수량·평단가만 저장.
- KB 계좌는 "연금" 위젯, 나머지 계좌는 "부부 주식 합산" 위젯에서 집계.
- 계좌 종류 예: 토스 / 메리츠현금 / 메리츠소수점 / KB(연금)

## 3. 주식 목표 (target)

**시트:** `family_portfolio`의 **`Config_Targets`** 탭

**입력 방법:**

- 시트에서 종목별 목표 수량 직접 수정
- 새 목표 추가: ticker / name / market / target 컬럼 채워서 새 행 추가
- 자동 저장. 다음 home 로드에 즉시 반영.

| 컬럼 | 예시 |
|---|---|
| ticker | TSLA |
| name | Tesla |
| market | NASDAQ |
| target | 100 |

**참고:**

- `current`, `progressPct` 등은 Apps Script가 자동 계산.
- home 위젯에서 `target` 도달하면 `✓` 표시.

## 4. 가계부 (whooing)

**완전 자동.** 별도 시트 입력 없음.

**흐름:**
```
whooing 앱에 거래 입력 (평소처럼)
       ↓
Apps Script (HMAC 인증) — 시간 트리거로 주1회 자동 sync
       ↓
구글 시트 `cashflow` 탭에 저장
       ↓
home 위젯이 fetch
```

**즉시 갱신하고 싶을 때:**

1. 구글 시트 → 확장 프로그램 → Apps Script
2. 함수 선택: `syncCashflow`
3. ▶ 실행

**참고:**

- whooing 앱에서 입력만 잘 해두면 됨. 시트는 손댈 필요 없음.
- API 키는 `PropertiesService`에 저장됨 (코드엔 없음).
- 위젯이 보여주는 데이터: 이번 달 수입/지출/저축률.

## 5. BTC

**입력 위치:** `btc` 앱 (남편과 같이 사용)

**시트:** `BTC_Config`, `BTC_Snapshots` 두 탭 자동 생성됨.

### 보유량/목표 수정
- 앱에서 보유량(`btc_holdings`) 또는 목표(`target_btc`) 탭해서 수정
- → 시트의 `BTC_Config` 탭에 자동 반영
- 한쪽(부부 중 누구든)이 수정하면 다른쪽도 새로고침 후 반영

### 스냅샷 기록
1. 앱의 **📸 스냅샷 버튼**
2. 현재 보유량 · BTC가격 · 평가금액 자동 미리보기
3. 메모 입력 (선택)
4. 저장 → `BTC_Snapshots` 탭에 한 행 추가

**참고:**

- BTC 시세는 앱에서 자동 조회. 시트엔 스냅샷 찍은 시점의 가격만 저장.
- 추이 차트는 `BTC_Snapshots`의 행들로 그려짐 — 스냅샷 자주 찍을수록 정밀.
- home 위젯은 가장 최근 스냅샷의 평가금액 표시.

## 트리거 종류

각 모듈의 갱신은 두 가지 방식:

- **Apps Script 시간 기반 트리거** → 가계부(주1회 자동 sync)
- **사용자 액션** → 나머지 4개 (시트 입력 / 앱 입력)

시간 트리거는 Apps Script의 **트리거** 메뉴에서 확인/수정 가능.
